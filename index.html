NNPKGM

No‑Nonsense Package Manager.
A deterministic, folder‑based, zero‑magic package manager for Windows.

Install

Download the installer PowerShell script from the Releases page:

install-nnpkgm.ps1

Then run:

powershell -ExecutionPolicy Bypass -File install-nnpkgm.ps1

This will:

  • download the latest NNPKGM ZIP release
  • extract it to C:\nnpkgm
  • add C:\nnpkgm and C:\nnpkgm\lnchrs to PATH
  • done

Basic Usage

nnpkgm install mypkg https://example.com/mypkg.zip
nnpkgm remove mypkg
nnpkgm list

Kirby Mode (Updates)

NNPKGM updates packages using the Kirby Protocol:

nnpkgm Kirby mypkg https://example.com/mypkg-latest.zip

Kirby Mode does:

  • inhale: delete old package folder
  • swallow: download new version
  • spit: extract fresh files
  • sparkle: regenerate launchers

No patching. No merging. No leftover files. Pure Kirby.

Philosophy

  • no installers
  • no scripts
  • no registry edits
  • no dependencies
  • no telemetry
  • no nonsense
